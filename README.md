# Deepfake Detective

Interative tool for deepfake and AI-generated image detection presentation.

## Features
- 11 Comparison cases
- Side-by-side view (Real vs Fake)
- Reveal artifacts with hotspots
- Minimalist and dark-themed UI

## Technical Stack
- Vanilla HTML5/CSS3
- Pure JavaScript
- StyleGAN2 generated sample faces
- Unsplash real human portraits
